## Git
- Инициализировать репозиторий: `git init`
- Коммиты — однострочные, без подписей, формат: `тип: краткое описание на русском`
- Типы коммитов:
  - `feat` — новая функциональность
  - `fix` — исправление бага
  - `chore` — настройка проекта, зависимости, конфиги
  - `style` — стили
  - `refactor` — рефакторинг без изменения поведения
  - `test` — тесты
- Пример: `git commit -m "chore: инициализация vite проекта"`
